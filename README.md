# Workforce Settings Remote

Independent settings micro-frontend. It exposes `./Settings` from `settingsMfe` and uses the versioned `@r01al/mfe-workforce-common-client` theme API.

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm start
```

`npm run dev` renders Settings independently at
`http://localhost:3006/settings`. The shell and other remotes are not required.
